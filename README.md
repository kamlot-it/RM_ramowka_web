# Ramówka

Ramówka Radia Meteor

## Getting Started

The application is intended to serve Radio Meteor as a schedule for the website - a reference point for what is currently happening on air, who hosts the program and what guests can be expected during each program.

### About Project

This project is builded for Web from Flutter project. Web build is desired to be hosted on Github Pages and ultimately should not need any maintenance except configuration on source Google Sheets.
